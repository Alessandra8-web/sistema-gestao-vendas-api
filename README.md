# Sistema de Gestão de Vendas - API

Projeto Back-End desenvolvido para o Sistema de Gestão de Vendas Online, voltado para a comercialização de caixinhas de som.

## Entrega 3 - Projeto Back-End

### Tecnologias utilizadas

- Node.js
- Express.js
- JavaScript
- SQLite
- npm
- Git e GitHub
- Trello para organização das tarefas

### Desenvolvimento

Foi criada uma API integrada ao Sistema de Gestão de Vendas Online, com versionamento utilizando Git e integração com repositório remoto no GitHub.

Foram desenvolvidas tarefas relacionadas à API e à interface do sistema, incluindo cadastro e listagem de clientes e produtos, registro de pedidos, confirmação de pagamento e geração de relatórios de vendas.

Foram implementadas no mínimo 8 tarefas da API e 8 tarefas da UI, conforme planejamento realizado no Trello.

### Organização do projeto

O desenvolvimento foi organizado e acompanhado através do Trello, seguindo a divisão das tarefas da primeira Sprint.

O código-fonte e o histórico de versionamento estão disponíveis neste repositório GitHub.
